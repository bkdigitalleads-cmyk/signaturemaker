# signaturemaker

Signature Maker for iPhone, on the App Store as "Electronic Signature Creator" (subtitle "Sign Documents & PDF Maker"). Draw or type a signature that looks like yours, export it as a clean transparent PNG for email, Word, Canva and forms, and sign any PDF from Mail or Files. Works offline; nothing leaves the phone. It makes a signature image and places it on your document; it does not verify identity or certify signatures.

Expo SDK 57, React Native, TypeScript, Skia, react-native-pdf, pdf-lib, RevenueCat. See CLAUDE.md for how shipping works and NOTES.md for the change log.

```
npm install
npx tsc --noEmit
npm test
npx expo export --platform ios
```
