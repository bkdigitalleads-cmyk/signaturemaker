# Signature Maker change log

Newest first. One entry per commit: date, version/build, what changed and why, and how it was checked.

- 2026-11-03: 1.0.0 build 1, the document signing flow (same branch, no build).
  - Documents tab (src/screens/Documents.tsx): "Sign a document", Open a PDF (Files, through expo-document-picker; images from Files work too) and A photo (Photos, through expo-image-picker's system picker, which needs no library access). One line says how to send a file from Mail or Files. Below, the last 20 signed files with Open (an in-app viewer), Share and Remove.
  - "Open in": app.json declares PDF and image document types with LSSupportsOpeningDocumentsInPlace false, so Signature Maker appears in Mail's and Files' share sheets and iOS copies the file into the app; App.tsx picks the file URL up with expo-linking (cold start and while running) and opens it for signing. If a document is already open it asks first. No share extension in 1.0.
  - Every incoming file is copied into the cache before it is read (src/store.ts `workingCopy`); the original is never written to. A photo is made upright through Skia and becomes a one-page PDF (its long side 842 points), so placing and flattening are the same for both.
  - Pages (src/ui/PageView.tsx): react-native-pdf in single-page mode with touch off, sized to the page's own shape (src/placement.ts `fitRect`), so placements line up with the page under them. It went in without config changes for Expo 57 (no config plugin is needed on iOS; react-native-blob-util is its peer), so the pdf-lib plus WebView fallback was not needed. Only an EAS build proves it compiles and draws.
  - Sign screen (src/screens/Sign.tsx): Add signature opens the library with the default first and highlighted (or Create, if the library is empty, then places the new one); Add initials, Add date (today, short, editable) and Add text (the typed name or "Your name", editable) are Pro. Drag to move; pinch anywhere on the page resizes the selected one; the round corner handle resizes too; Remove. Several per page, any page, with previous and next. VoiceOver: each placement has Make bigger, Make smaller and Remove actions.
  - Hit testing, resizing and the coordinate maths are pure (src/placement.ts): display points (top left, as the page is shown) to PDF user space for /Rotate 0, 90, 180 and 270 and crop boxes that do not start at 0,0; pdf-lib's draw rotation undoes the page rotation so stamps stay upright as shown.
  - Done signing (src/documents.ts, src/flatten.ts): pdf-lib embeds each signature's transparent PNG and draws dates and text in Helvetica at the converted coordinates, then saves "<original> signed.pdf" (" 2" and so on when a name is taken) in its own folder. A photo can be saved as PDF or JPG (composed with Skia). Password-locked PDFs are refused with a plain message. Then "Signed." with Send it back (share sheet), Send in Mail (expo-mail-composer, when Mail is set up) and Save to Files.
  - Free and Pro: the first signed document is free and clean; later free ones open the paywall first, and closing it saves the file with the small corner mark on each signed page. The first share or mail of the first signed document asks for a rating (never while a document is open: src/reviews.ts gets the guard from the Sign screen).
  - Checked: npx tsc --noEmit clean; npx expo export --platform ios bundles. A four-page PDF (Letter, A4 at 90, Letter at 180, A4 landscape at 270) was flattened in Node with src/flatten.ts and rendered with pdftoppm: text placed at the top left as shown and an image at the bottom right as shown land in the same visual spot, upright, on all four.

- 2026-11-03: 1.0.0 build 1, the signature canvas (same branch, no build).
  - Create tab (src/screens/Create.tsx) is the hero: "Sign here" over a wide sheet of paper with a thin signing line and a small cross, the pen row, and one "Save signature" button (64 pt). Undo, redo, clear and Wide sit quietly under the pad.
  - Pad (src/ui/Pad.tsx): Skia draws the pen engine's filled outlines; touches come from the plain responder on a view over the canvas, so points stay in the pad's own space. Only the live stroke is re-outlined while drawing (once per frame); finished strokes are outlined once. Apple Pencil force drives the Ink pen when the screen reports it.
  - Pen engine (src/stroke.ts): centripetal Catmull-Rom smoothing through every touch point, resampled every 2 points; Ink (thickness from speed, or from Pencil pressure), Ballpoint (even and thin), Marker (even and bold), Fountain (thick on down-strokes, thin on up-strokes); soft tapers at the ends; three thickness steps. The outline is a strip of quads with round caps and joins, all wound one way, so a nonzero fill unions them with no seams or holes.
  - Pen row (src/ui/PenRow.tsx): each pen's glyph is a real squiggle from the engine, not an icon. Four inks (black, navy, blue, red) and three thicknesses. Marker and Fountain show a lock for free users and open the paywall.
  - Wide mode: the pad turned sideways across the whole screen (the app stays portrait); strokes go in scaled up and come back scaled to fit, with their line weight kept (`fitStrokes`, a per-stroke width factor).
  - Type instead: a name, its live preview on paper, the four inks, and all twelve fonts as rows showing that name. Eight fonts carry a lock for free users. Typed signatures are rendered through Skia (Path.MakeFromText with the bundled font file) so the PNG is the same quality as a drawn one.
  - Library tab (src/screens/Library.tsx): each signature on paper with its initials beside it, its name and a Default tag. Tap one for Export, Make initials (Pro), Use as default, Rename, Move up, Move down, Delete. Stored as signatures/index.json plus transparent 3x PNGs (src/signatures.ts), with the raw points or the typed words kept.
  - Initials: the same screen in initials mode for a saved signature, draw or type, stored with it.
  - Checked: npx tsc --noEmit clean; npx expo export --platform ios bundles.
